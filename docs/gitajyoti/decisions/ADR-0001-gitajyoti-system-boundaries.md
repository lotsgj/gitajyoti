# ADR-0001: Gita Jyoti system boundaries

- Status: Accepted
- Implementation: Implemented
- Supersedes: None
- Superseded by: None
- Date: 2026-09-10

## Decision

Gita Jyoti is the complete site. The site contains multiple regions. Landing and MyGita are the current regions. Specialized learning applications are products, not regions and not internal MyGita features.
