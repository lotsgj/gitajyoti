# ADR-0007: Product-specific API contracts

- Status: Accepted
- Implementation: Planned
- Supersedes: None
- Superseded by: None
- Date: 2026-09-10

## Decision

Each learning product owns a product-specific API contract, such as `gita4children.api` or `gitasara.api`. Filesystem directories use corresponding hyphenated names. Common integration concepts promote consistency without imposing one generic provider API.
