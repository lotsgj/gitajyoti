## Optimization evidence

- Fixture Discover, offline cached Discover, and Atmajyoti private-data access each make **0 API calls**.
- Warm unchanged Discover makes **1 call**, versus **2 calls** when the catalogue is first loaded—a 50% call reduction, with no repeated summaries body.
- Two visits to the same Experience download its detail only **once**; the two lightweight manifest checks confirm whether that saved detail remains current.
- An interest-only or Profile-only external change makes **2 calls**: one shared private manifest plus only the changed projection. Unchanged private projections are not fetched.
- Three tested mutations reuse their response bodies and make **0 follow-up projection GETs**.

The budgets are exact regression constraints. Any added, removed, or duplicated API call fails the suite and blocks the standard CI check until the implementation or declared budget is deliberately revised.
