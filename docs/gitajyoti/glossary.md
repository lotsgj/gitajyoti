# Glossary

## Site

**Gita Jyoti** is the complete site and ecosystem described by this repository.

## Region

A **region** is a major area within the Gita Jyoti site. A region has a distinct purpose and user journey, but remains part of the site. This term does not mean geography, cloud infrastructure, or an ARIA landmark.

Current regions:

- **Landing:** the public introduction to Gita Jyoti.
- **MyGita:** the learner gateway and orchestration region.

## Product

A **product** is an independently evolving learning application. It owns its curriculum delivery, learning interactions, and product-specific progress. Examples include Gita for Children and Gita Sāra.

## Experience

An **experience** is an offering that a learner can discover or enrol in through MyGita. A product may deliver one or more experiences.

## Repository

A client-side boundary that exposes domain operations to UI code and hides whether data comes from fixtures or an API.

## API identity

The stable architectural name of an API, written with a dot, such as `mygita.api` or `gita4children.api`. Filesystem directories use hyphens, such as `mygita-api`.
