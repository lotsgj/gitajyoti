# mygita.api

Filesystem ID: `mygita-api`

This contract describes communication between the MyGita client and MyGita server: catalogue, authentication, profile, onboarding, enrolment, interests, journeys, activities, launch, and aggregated progress.

The authoritative OpenAPI document is [`contracts/mygita-api/openapi.yaml`](../../../../contracts/mygita-api/openapi.yaml). Password Account creation and login are implemented by the client contract/provider boundary; server implementation and compatibility verification are in progress.
