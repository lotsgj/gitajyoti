# Gita Jyoti documentation

Gita Jyoti is the complete site. The site contains multiple **regions**, each serving a distinct part of the visitor or learner journey. The current regions are the public Landing region and the learner-facing MyGita region.

Gita Jyoti also connects learners to specialized **products**. Products deliver the learning itself and may run as independent applications, such as `gita4children.app` and `gitasara.app`. MyGita discovers, enrols, launches, and aggregates progress across these products; it does not contain or own their learning implementations.
