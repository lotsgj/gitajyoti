# Product integration

MyGita provides a consistent learner gateway while products deliver specialized learning. An experience and a product are separate concepts: an experience is enrolable; a product is the application that delivers it.

Common integration concepts include product identity, learner reference, enrolment reference, launch request, launch result, progress summary, completion status, correlation ID, and standard error information.

Each product owns a product-specific API contract. Shared concepts encourage consistency but do not force all curricula and learning models into one generic provider API.
